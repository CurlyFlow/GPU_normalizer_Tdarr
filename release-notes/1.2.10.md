## TLDR

- `1.2.10` hardens standalone and 3-node reliability, A/V sync preservation, concurrency scheduling, and real-world MKV/MP4 edge cases while keeping **`100%` exact decoded audio parity** (`energy_similarity=1.000000000`, `rms_diff=0`, bit-identical decoded PCM SHA-256) against Tdarr CPU `Normalize Audio`.
- Long combined 5.1 plus generated 2-channel fallback jobs run **`4.598x`** faster than CPU on `10min`, **`5.045x`** on `30min`, and **`4.876x`** on `60min` (`292.4s` vs `1426.0s` CPU; `-25.2%` to `-27.8%` faster than `1.2.8`, and `-3.7%` faster than `1.2.9` on `60min`).
- **Fixes standalone Matroska (`.mkv`) A/V sync on offset audio tracks** (`mkvMuxOffsets.js` with `-copyts` + per-stream `-itsoffset` and AAC priming compensation), enables standalone ISO MP4/MOV direct clock muxing and `44.1 kHz -> 96 kHz` normalized EOF clock transport, and switches `Remove Other Languages` to a non-destructive `false` default.
- **Adds host-wide `Max Concurrent CPU Tasks`** (shared across jobs/plugins) and releases the GPU slot before CPU-bound final muxing so another job can use the GPU immediately.
- **Hardens real-world MKV → MP4 & long-movie verification:** fixes 32-bit `audio_clock_mux` chapter `stts` overflow by excluding subtitle/data microsecond timescales, binds installed plugin modules by `sha256 + bytes` across Tdarr Node plugin re-syncs, handles Matroska FLAC lace snap-backs, omitted MP4 `colr` default `tv -> null`, trailing `mov_text` `btrt` boxes, synthesized MP4 `tkhd` creation time, and fragment index receipt bounds.
- **Publishes the neutral `Media Pipeline Helper` companion source** under `src/mediaPipelineHelper/` alongside live neutral Tdarr WebUI flow & settings screenshots in `pictures/` and updated `README.md` documentation.
- The full `60s`, `10min`, `30min`, `60min` fresh `SRC_CPU` source-reference audit and the complete 6-codec + 10-scenario normalize-scope + `Prepare Audio For MP4` smoke suite all passed `100%` decoded parity.

## Changes

- **Standalone A/V Sync & Safer Defaults:**
  - Adds [`mkvMuxOffsets.js`](../src/gpuNormalizeAudio/lib/mkvMuxOffsets.js) and Matroska `-copyts` + per-stream `-itsoffset` support in [`outputMux.js`](../src/gpuNormalizeAudio/lib/outputMux.js), preserving exact start-time alignment (including AAC priming compensation) on standalone MKV files with delayed or multi-offset audio streams.
  - Restores standalone ISO MP4/MOV direct clock muxing and `transportAudioOutput` with `eofContext` (supporting non-integral resamples such as `44.1 kHz -> 96 kHz` AAC stereo) while checking the actual package container rather than `audioCompatibilityContainer` when `Prepare Audio For MP4` is enabled on MKV inputs.
  - Changes `Remove Other Languages` default to `false` (non-destructive copy of unselected languages unless explicitly enabled) and routes empty-audio / no-language-match outcomes cleanly to Output 2.
- **Host-Wide CPU & GPU Concurrency:**
  - Adds `Max Concurrent CPU Tasks` (default `1`) across running jobs/plugins and releases the GPU normalize slot before CPU-bound final muxing and verification.
- **ISO MP4/MOV, Matroska & Long-Movie Hardening:**
  - Excludes subtitle/data microsecond timebases from `audio_clock_mux` and `movieTimescale.js` so long MP4 chapter durations never overflow 32-bit `stts`.
  - Stages `audio_clock_mux` cleanly for read-only / `0644` Tdarr Node extractions and binds installed plugin modules by `sha256 + bytes` across Tdarr Node plugin re-syncs.
  - Hardens MKV → MP4 verification for omitted MP4 `colr` default `tv -> null`, trailing `mov_text` `btrt` boxes, synthesized `tkhd` creation time, dropped Matroska stream titles, Matroska FLAC lace snap-backs, benign FFmpeg 7.1 missing QT chapter notices, and large fragment-index receipt bounds.
- **Public `Media Pipeline Helper` & Documentation:**
  - Moves the neutral companion helper source to `src/mediaPipelineHelper/`, replaces schematic UI drawings with live neutral Tdarr WebUI screenshots in `pictures/`, and adds full 3-node pipeline documentation in `README.md`.

  - `codec_multi_audio` (4-track multi-codec MKV: AAC + AC3 + E-AC-3 + DTS)
- All 10 multi-language normalize-scope scenarios (`blank_all`, `keyword_all`, `ui_default_eng`, `only_eng_keep_others`, `only_eng_removes_others`, `only_eng_no_generated_stereo`, `selected_languages_only`, `all_languages_generate_all_stereo`, `track_order_eng_first`, and `no_language_match_output_2`) plus `Prepare Audio For MP4` compatibility smoke passed.

## Caveats

- Only `192k` AAC output and the tested Tdarr CPU `Normalize Audio` contract are covered by this release validation.
- Short media (`60s` and codec smokes) remains a smoke/parity gate, not headline speed evidence.
- Language filtering uses source metadata. Wrong or missing language tags cannot be corrected automatically.
