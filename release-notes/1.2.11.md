## TLDR

- `1.2.11` hardens **standalone** and **3-node (`Media prepare` → `GPU Normalize Audio` → `Media finish`)** reliability, Plex Direct-Play `.mp4` packaging, lossless AV1 HDR10 / Dolby Vision Profile 10 preservation, `mov_text` subtitle & non-zero-start chapter muxing, and multi-AU TrueHD / offset-audio verification while keeping **`100%` exact decoded audio parity** (`energy_similarity=1.000000000`, `rms_diff=0`, bit-identical decoded PCM SHA-256) against Tdarr CPU `Normalize Audio`.
- Long combined 5.1 plus generated 2-channel fallback jobs run **`4.598x`** faster than CPU on `10min`, **`5.045x`** on `30min`, and **`4.876x`** on `60min` (`292.4s` vs `1426.0s` CPU; `-25.2%` to `-27.8%` faster than `1.2.8`). The GPU compute and AAC-LC encode hot-path is unchanged from `1.2.10`.
- **Plex Direct-Play `.mp4` container & video policy (`Media prepare` + `Media finish`):** writes `-movflags +faststart` (`moov` before `mdat`) + `+use_metadata_tags` MP4 packages, tags HEVC streams as `hvc1` across both `prepare` and `finish`, stream-copies **AV1 (`av01`)** losslessly (preserving 10-bit SMPTE ST 2086 HDR10 `mdcv`/`clli` and Dolby Vision Profile 10 `dvwC`), and preserves source VUI `chroma_location` via `hevc_metadata` when NVENC encodes legacy video codecs to HEVC `hvc1`.
- **ISO clock carrier, subtitles, chapters & lossless surround hardening (Standalone & 3-Node):** fixes `audio_clock_mux` / `audio_clock_merge` CTTS B-frame STTS stream duration restoration, non-reentrant `mov_text` fragment flushing and cross-timebase `av_compare_ts` end-packet ordering, Dolby Vision Profile 10 (`dv_profile >= 10`) `dvwC` box emission, non-clamped QuickTime/MP4 chapters via a synthesized `[0..start]` pre-chapter when `chapters[0].start > 0`, multi-AU TrueHD interior `pts=N/A` linear frame continuation, `preparedOriginalEnd` `commonOffset` projection on offset audio tracks, bounded 2-stream `verifyCopiedAudio` concurrency, and standalone `outputFinalizer` non-object `eofContext` safety.
- Verified across the `60s` parity smoke, all 6 release codec smokes, all 10 multi-language normalize-scope scenarios, `Prepare Audio For MP4`, and all 6 native 3-node SDR / HDR10 / Dolby Vision AV1 / Blu-ray NVENC / long TrueHD proofs.

## Changes

- **Plex Direct-Play MP4 Container, Lossless AV1 & Dolby Vision (`Media prepare` + `Media finish`):**
  - Adds [`mp4ContainerPolicy.js`](../src/mediaPipelineHelper/lib/mp4ContainerPolicy.js) and [`mediaIsoCarriers.js`](../src/gpuNormalizeAudio/lib/mediaIsoCarriers.js) so `Media finish` writes `-movflags +faststart` + `-movflags +use_metadata_tags` MP4 files (`moov` before `mdat` with preserved container tags), tags HEVC streams as `hvc1` across both `prepare` and `finish`, and stream-copies already Direct-Play-ready **HEVC (`hvc1`)** and **AV1 (`av01`)** video losslessly.
  - Preserves SMPTE ST 2086 HDR10 (`mdcv` `1/50000` primaries & `1/10000` luminance, `clli`) and Dolby Vision Profile 10 (`dv_profile = 10`, `dvwC` box inside `av01` sample entries) end-to-end across MKV → MP4 preparation, normalization, and final publication.
  - Preserves source VUI `chroma_location` (`topleft` / `left` / `center`) via `-bsf:v hevc_metadata=chroma_sample_loc_type=...` when NVENC encodes legacy video codecs to HEVC `hvc1`.
- **ISO Clock Carrier, `mov_text` Subtitles & Chapter Boundaries (Standalone & 3-Node):**
  - Fixes CTTS B-frame STTS duration restoration (`clock_restore_stream_duration`) in [`audio_clock_mux.c`](../src/gpuNormalizeAudio/runtime/bin/audio_clock_mux.c) and [`audio_clock_merge.c`](../src/gpuNormalizeAudio/runtime/bin/audio_clock_merge.c) so copied video streams with negative CTTS composition offsets never collapse their final STTS sample delta to `0`.
  - Rebuilds the bundled zero-transcode `audio_clock_mux` carrier with upstream FFmpeg `movenc` fixes for Dolby Vision Profile 10 (`dv_profile >= 10` `dvwC`), non-reentrant `mov_text` fragment end-packet flushing (`AV_PKT_FLAG_KEY`), and cross-timebase `av_compare_ts` subtitle end-packet ordering, alongside relaxed non-video fragment-run index bounds in [`mediaFragmentRuns.js`](../src/gpuNormalizeAudio/lib/mediaFragmentRuns.js).
  - Synthesizes a deterministic `[0..start]` pre-chapter via `buildMp4LeadingChapterMetadata` (`makeZeroOriginShift`) whenever `chapters[0].start > 0` so FFmpeg MP4/QuickTime chapter tracks never clamp Chapter 0 back to `0`, and verifies exact chapter boundaries in [`mediaMetadataEvidence.js`](../src/gpuNormalizeAudio/lib/mediaMetadataEvidence.js).
  - Guards standalone `outputFinalizer.js` against non-object `eofContext` inputs while keeping full 3-node handoff verification strict.
- **Lossless Multi-AU Surround & Offset Audio Window Verification:**
  - Handles multi-AU TrueHD packets whose interior decoded frames report `pts=N/A` in [`mediaOriginalAudioWindow.js`](../src/gpuNormalizeAudio/lib/mediaOriginalAudioWindow.js) via linear sample-rate continuation instead of misclassifying interior frames as timestamp discontinuities.
  - Projects `preparedOriginalEnd` into the prepared container timeline by subtracting `commonOffset` (`audioClockPlan.js`, `mediaAudioEofContext.js`, `mediaClockVerification.js`) so MKV inputs with shifted video/audio origin preserve exact audio EOF windows.
  - Bounds `verifyCopiedAudio` (`mediaCopiedAudio.js`) to 2 concurrent `ffprobe` workers instead of unbounded parallel decode fan-out on multi-track files.

## Codec Smoke

- All 6 release codec smokes passed `100%` decoded parity (`energy_similarity=1.000000000`, `rms_diff=0`):
  - `codec_aac_stereo` (`44.1 kHz -> 96 kHz` AAC stereo MP4)
  - `codec_ac3_5_1` (offset 5.1 AC3 MKV + generated 2ch stereo)
  - `codec_eac3_5_1` (5.1 E-AC-3 MP4 + generated 2ch stereo)
  - `codec_dts_5_1` (5.1 DTS-HD MA MKV + generated 2ch stereo)
  - `codec_mp3_stereo` (44.1 kHz MP3 stereo MKV)
  - `codec_multi_audio` (4-track multi-codec MKV: AAC + AC3 + E-AC-3 + DTS)
- All 10 multi-language normalize-scope scenarios (`blank_all`, `keyword_all`, `ui_default_eng`, `only_eng_keep_others`, `only_eng_removes_others`, `only_eng_no_generated_stereo`, `selected_languages_only`, `all_languages_generate_all_stereo`, `track_order_eng_first`, and `no_language_match_output_2`) plus `Prepare Audio For MP4` compatibility smoke passed.

## Caveats

- Only `192k` AAC output and the tested Tdarr CPU `Normalize Audio` contract are covered by this release validation.
- Short media (`60s` and codec smokes) remains a smoke/parity gate, not headline speed evidence.
- Language filtering uses source metadata. Wrong or missing language tags cannot be corrected automatically.
