## TLDR

- `1.2.9` delivers a major long-media speedup and exact original-relative ISO MP4/MOV A/V clock integrity over `1.2.8` while keeping `100%` decoded audio parity (`energy_similarity=1.000000000`, `rms_diff=0`) against Tdarr CPU `Normalize Audio`.
- Long combined 5.1 plus generated 2-channel fallback jobs are now **`5.104x`** faster than CPU on `10min`, **`4.940x`** on `30min`, **`4.529x`** on `60min` (`4.713x` on idle host), and **`5.260x`** on `90min` (`6m 57s` vs `36m 33s` CPU).
- Compared with `1.2.8`, combined GPU wall time improved by **`28%`** on `10min` (`71.1s -> 51.5s`), **`31%`** on `30min` (`202.8s -> 139.4s`), **`24%`** on `60min` (`399.4s -> 303.5s`), and **`34%`** on `90min` (`632.8s -> 416.9s`), even while adding full zero-tolerance ISO MP4/MOV source-clock preservation and verification.
- Moves `192 kHz f64 -> 96 kHz f32` SWR downsampling and apply-pass `48 kHz f32 -> 192 kHz f64` SWR upsampling onto CUDA, parallelizes exact AAC-LC encoding across channels (`aac_encode_mt`), parallelizes per-channel native loudness stats with fused AVX2-FMA `48 kHz -> 192 kHz` upsampling, and retimes ISO MP4/MOV audio directly during final mux (`audio_clock_mux --mux-audio`).
- Moves the release plugin path to `FlowPlugins/LocalFlowPlugins/audio/gpuNormalizeAudio/1.2.9/` (so Tdarr's *Update Community Plugins* no longer overwrites or deletes the plugin) and adds a one-command [`install.sh`](../install.sh) installer/updater.
- The installed-plugin `60s` smoke and ISO MP4 codec smokes passed exact decoded parity (`energy_similarity=1.000000000`, `rms_diff=0`).

## Performance

`1.2.9` was compared against Tdarr's legacy CPU-only `Normalize Audio` output. The benchmark source is a 5.1 file without an existing stereo track, so the GPU job outputs both the normalized original 5.1 stream and a generated normalized 2-channel fallback. Both decoded output streams were compared against CPU output and passed with `energy_similarity=1.000000000` and `rms_diff=0` across the full matrix.

`SRC_CPU` means the Tdarr CPU `Normalize Audio` reference/cache. For generated fallback, the harness creates the matching 2-channel source and runs CPU `Normalize Audio` on it. `OUR_CPU` means CPU-side work inside the GPU plugin run.

`Speed vs SRC_CPU` above `1.0x` means the GPU plugin was faster than CPU for that case. Values below `1.0x` mean the GPU plugin was slower.

## Changes

- **CUDA SWR Resamplers & Parallel GPU Kernels:**
  - Ports exact FFmpeg `libswresample` `192 kHz f64 -> 96 kHz f32` 68-tap Kaiser FIR downsampling onto CUDA (`4×` less D2H/pipe memory traffic).
  - Ports exact `48 kHz f32 -> 192 kHz f64` 4× Kaiser polyphase FIR upsampling onto CUDA for original apply passes.
  - Adds shared-memory `nz_mask` loudness histogram, 256-thread parallel true-peak limiter, and 256-thread pre-threshold 6-channel safe-skip apply kernels.
- **Bit-Exact Multi-Channel Parallel AAC-LC Encoder (`aac_encode_mt`):**
  - Parallelizes per-channel `win_mdct` and `search_for_quantizers_twoloop` across channels while keeping psychoacoustics, TNS, PNS, IS/MS, and bitstream writing strictly sequential (`100%` packet- and PCM-identical to stock Jellyfin FFmpeg 7.1.2 AAC-LC, including `5.1(side)` PCE layouts).
  - Stages a job-private executable copy in `stream_processes.py` so plugin extraction permissions or in-place updates cannot trigger `PermissionError` or `SIGBUS`.
- **Fused AVX2-FMA Native Channel Stats & Pipeline Overlap:**
  - Adds a persistent per-channel `pthread` pool for native `f64le` channel stats and fused AVX2-FMA `48 kHz f32 -> 192 kHz f64` K-weighting for `first-pass-input` (`0`-ULP bit-exact against FFmpeg).
  - Removes the legacy `24s` stereo-fallback start delay so 2-channel first-pass measurement overlaps completely with 5.1 GPU work.
- **Direct Clock Final Mux & Original-Relative ISO MP4/MOV Integrity:**
  - Adds `audio_clock_mux --mux-audio` with `1 MiB` AVIO buffering and direct clock final muxing (`finalClockMux.js`), eliminating redundant remux and decode passes while preserving exact zero-tolerance ISO MP4/MOV source clocks, normalized EOF windows, and stream metadata.
  - Parallelizes transport verification file digests (`worker_threads`) and overlaps initial digests with clock evidence prewarming without weakening any verification check.

## Codec Smoke

- Verified ISO MP4 codec smokes including `44.1 kHz -> 96 kHz` AAC stereo and E-AC-3 5.1 (`5.1(side)` + generated 2ch stereo) with `energy_similarity=1.000000000` and `rms_diff=0`.
- Standalone multi-language and normalize-scope contracts remain covered by the automated contract test suite (`ui_default_eng`, `selected_languages_only`, `selected language with Remove Other Languages=false`, and `no language match`).

## Caveats

- Only `192k` AAC output and the tested Tdarr CPU `Normalize Audio` contract are covered by this release validation.
- Short media remains a smoke/parity probe, not public speed evidence.
- Language filtering uses source metadata. Wrong or missing language tags cannot be corrected automatically.
